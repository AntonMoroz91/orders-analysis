# orders-analysis
Анализ заказов интернет-магазина за июль 2023 года. Программа на Python читает JSON-файл с данными о заказах, обрабатывает их и вычисляет: самый дорогой заказ, заказ с максимумом товаров, день с наибольшим числом заказов, самого активного пользователя, пользователя с макс. суммой покупок, среднюю стоимость заказа и среднюю цену товара.
