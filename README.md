# Анализ заказов интернет-магазина за июль 2023

## Описание проекта
Программа анализирует данные о заказах из JSON-файла и вычисляет ключевые метрики:
- Самый дорогой заказ
- Заказ с наибольшим количеством товаров
- День с максимальным числом заказов
- Пользователь с наибольшим количеством заказов
- Пользователь с максимальной суммой покупок
- Средняя стоимость заказа
- Средняя стоимость товара

## Файлы
- `orders_analysis.py` - основной код программы
- `orders_july_2023.json` - данные о заказах
- `README.md` - описание проекта

## Запуск
1. Убедитесь, что все файлы находятся в одной папке.
2. Запустите файл `orders_analysis.py`.
3. Результаты появятся в консоли.

## Технологии
- Python 3
- JSON
